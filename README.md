# English For Every Opportunity

Fase 1  Crie um aplicativo chamado Speak2Co. (este é o nome do meu produto)

O aplicativo deve possuir aparência premium nas cores azul marinho, dourado e branco, conforme os anexos

O slogan é:

English for Every Opportunity.

Fase 2
Quero tela de login.

Cadastro de alunos.

Plano gratuito e plano Premium.

Chat de IA para prática de inglês.

Simulador de entrevista.

Criar os acessos para os subprodutos: 
 Speak2Hire (arte conforme anexo)

 Speak2Travel (arte conforme anexo)

Plano de estudos personalizado.

Painel de evolução.

Ranking de fluência.

Certificados.

Fase 3 — Ajustar

Quero conversar com a IA como se fosse um funcionário.

Exemplo:

Aumente o tamanho do logo.

ou

Quero o botão dourado.

ou

Troque a fonte.

ou

Quero uma tela parecida com a Netflix.

⸻

Fase 4 — Conectar a IA

Depois basta informar sua chave da OpenAI.

A IA passa a responder dentro do aplicativo.

Ela poderá:

* conversar em inglês

* corrigir pronúncia

* corrigir gramática

* criar exercícios

* fazer entrevistas
* Simular situações em viagens (aeroporto, hotel, passeios turísticos...)

⸻

Fase 5 — Firebase

No Firebase você cria:

* login Google

* login Apple

* login por e-mail

* banco de dados dos alunos

O Lovable faz praticamente toda a integração.

⸻

Fase 6 — Pagamentos

Conecte:

* Stripe (para clientes internacionais)

* Mercado Pago (para Brasil)

Assim o aluno compra a assinatura diretamente pelo aplicativo.
